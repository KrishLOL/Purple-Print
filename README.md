# Western Eng Insider

Course and professor reviews for Western University's Faculty of Engineering. Not affiliated
with Western University or the Faculty of Engineering — built by students, reviews are
site-native only (no scraped data).

## Stack

Next.js 16 (App Router, TS strict) · Tailwind CSS v4 · Prisma 7 (`prisma-client` generator,
`@prisma/adapter-pg`) · PostgreSQL · Zod · Vitest.

## Getting started

```bash
pnpm install
cp .env.example .env      # then fill in DATABASE_URL etc.
pnpm db:dev                # starts a local Postgres via `prisma dev` (no Docker needed)
pnpm db:push                # push the schema
pnpm db:seed                # seed disciplines (+ courses/profs/reviews from milestone 2 on)
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). The design system lives at `/styleguide`.

### Local Postgres, two ways

- **`prisma dev`** (default, no install required) — `pnpm db:dev` starts it, `pnpm exec prisma dev ls`
  shows the connection strings. Use the raw TCP `postgres://...` string (not the `prisma+postgres://`
  one) for `DATABASE_URL` — the driver adapter needs a wire-protocol-compatible URL, not Prisma's
  proxy protocol.
- **Docker** — `docker-compose.yml` is included if you'd rather run real Postgres. Switch
  `DATABASE_URL` to `postgresql://weu:weu@localhost:5432/western_eng_insider?schema=public` and run
  `docker compose up -d`.

## Notes for this codebase

- Prisma 7 requires a driver adapter (`@prisma/adapter-pg`) — see `lib/db.ts`. There is no
  bare-URL `new PrismaClient()` mode anymore.
- The generated Prisma client lives at `app/generated/prisma` (gitignored, regenerated by
  `prisma generate` / on install). It's excluded from ESLint and shouldn't be hand-edited.
- Design tokens are CSS custom properties in `app/globals.css`, mapped into Tailwind via
  `@theme inline`. Dark is the default theme; light is opt-in via `data-theme="light"` on
  `<html>` (see `components/theme-toggle.tsx`).
